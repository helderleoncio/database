# Banco de Dados II

Proposta de resumo expandido de análise crítica de artigos em português

## Apresentação da atividade

Cada uma das oito equipes deverá analisar um artigo científico em português e produzir um resumo expandido. Não será obrigatória a implementação de um banco de dados ou a reprodução dos experimentos.

A seleção reúne artigos da SBC Open Library, biblioteca digital da Sociedade Brasileira de Computação. Os links de acesso estão indicados em cada proposta.

## Orientação comum para os oito resumos

> Cada equipe deverá produzir um resumo expandido de análise crítica do artigo indicado, apresentando o problema investigado, os objetivos, a metodologia empregada pelos autores, os principais resultados e as limitações do estudo. O trabalho deverá estabelecer relações com os conteúdos de Banco de Dados II. Não será obrigatória a implementação ou reprodução dos experimentos.

### Uso das fontes

Os artigos indicados são as fontes centrais dos trabalhos. Os documentos da disciplina continuam como orientação de formato e avaliação, não como substitutos da fundamentação científica.

Antes da entrega, cada equipe deverá conferir no próprio artigo os dados completos de autoria e publicação e referenciar explicitamente a fonte analisada. As contribuições e os resultados dos autores devem ser distinguidos das interpretações elaboradas pelos estudantes.
